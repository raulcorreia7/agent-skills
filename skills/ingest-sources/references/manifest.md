# Manifest

Record these fields when they apply:

- Source owner, requested identifier, canonical identifier, version, locale,
  license locator, and terms locator.
- Retrieval time, final URL, redirect chain, status, media type, `ETag`,
  `Last-Modified`, `Content-Digest`, API version, and credential class without
  secret values.
- Raw byte length and SHA-256. For repositories, record the commit, submodule
  commits, archive members, and Git LFS policy.
- Converter, parser, OCR engine, or model name and version, settings, times,
  warnings, and derived artifact hashes.
- Exact raw artifact hash and source spans for each derived artifact.
- Title, language, schema, headings, page or line spans, object paths, symbol
  paths, parent IDs, and neighbor IDs.
- Chunk ID, exact text hash, source spans, deduplication group, aliases, and
  tokenizer or model version when used.
- Freshness rule, validation time, access class, retention period, and
  superseded or deleted state.
