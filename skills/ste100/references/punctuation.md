# Punctuation

## Rules 8.1–8.3

| Rule | Operational check | Official PDF pages |
|---|---|---|
| 8.1 | Use standard English punctuation except the semicolon. Use the applicable style guide for unspecified punctuation. | 107–108 |
| 8.2 | Use hyphens only to connect directly related words. | 107–109 |
| 8.3 | Use parentheses only for a reference, identifier, abbreviation, singular or plural form, explanation, or alternative. | 107, 109–110 |

## Checks

- Do not use a semicolon. Divide its clauses into sentences.
- Balance parentheses and quotation marks.
- Use parentheses only for a reference, item or step identifier, abbreviation,
  singular/plural form, explanation, or alternative.
- Use a no-space hyphen only between directly related words. A spaced dash does
  not join words.
- Apply the applicable publication style guide for punctuation questions that
  Section 8 does not define.

Example:

```text
Open the access panel. Remove the filter.
```

Do not join these instructions with a semicolon.

Source: Rules 8.1–8.3, official PDF pages 107–110.

## Automation Boundary

Software can find semicolons and unbalanced delimiters. Semantic use of
parentheses and whether words are directly related require review.
