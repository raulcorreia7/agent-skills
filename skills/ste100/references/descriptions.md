# Descriptions

These rules apply to descriptions. Descriptive writing gives information. It
does not give imperative commands.

## Description Rules — 6.1–6.6

| Rule | Operational check | Official PDF pages |
|---|---|---|
| 6.1 | Introduce information gradually and keep one subject in each sentence. | 95–96 |
| 6.2 | Use the same key words and phrases. Do not change them. Use connectors to identify new, different, sequential information, or a result. | 95–98 |
| 6.3 | Keep each sentence to 25 counted words. | 95, 98–99 |
| 6.4 | Put related information in the same paragraph. | 95, 99–100 |
| 6.5 | Give each paragraph one topic and start it with a topic sentence. | 95, 100–101 |
| 6.6 | Keep each paragraph to six sentences or fewer. | 95, 101 |

The topic sentence gives the paragraph's most important or new information and
connects it to the earlier text. The remaining sentences extend that topic.
In sequence, the topic sentences must form an outline of the description.
Start a new paragraph for a new topic.

Use active voice unless the agent is genuinely unknown. Passive voice does not
remove the one-subject limit, and an audit must not invent a false agent.

Source: Rules 6.1–6.6, official PDF pages 95–101.

## Automation Boundary

Software can count sentences in a paragraph and find sentences above the word
limit. It cannot reliably determine a paragraph topic, topic sentence,
information sequence, or grammatical subject. Review those requirements.
