# Official Source And Evidence

- Title: *ASD-STE100 Simplified Technical English — Standard for Technical
  Documentation*
- Issue and date: Issue 9, 2025-01-15
- Publisher and copyright owner: Aerospace, Security and Defence Industries
  Association of Europe (ASD)
- Official source:
  <https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf>
- Extent: 434 PDF pages

The official PDF is authoritative. This portable skill does not bundle or
cache it.

## Evidence Levels

Use the local references and analyzer without network access for unverified
work. Make a formal compliance or verification claim only when the agent can
access an authorized official copy. If access fails or a rule or entry remains
unresolved, report the limitation and unresolved items. Do not add a status
disclaimer to normal output.

For a rule dispute, cite the exact rule and the official PDF page shown in the
applicable local reference. For a dictionary dispute, inspect pages 131–144 for
the dictionary mechanics and all information in the applicable entry.

Example formal evidence record:

```text
Sentence: Open the access panel.
Result: Pass
Evidence: Rule 5.3, official PDF pages 89–90
```
