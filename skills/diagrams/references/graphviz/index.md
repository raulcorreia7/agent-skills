# Graphviz Router

Load `core.md` for all DOT authoring. Then load only the file matching the
required engine, composition feature, or formal notation.

| Trigger | File |
|---|---|
| Layered directed process, dependency, or hierarchy | `layout-dot.md` |
| Small undirected spring-model network | `layout-neato.md` |
| Medium clustered force-directed network | `layout-fdp.md` |
| Large overview-scale network | `layout-sfdp.md` |
| Cycle or ring topology | `layout-circo.md` |
| Radial hierarchy from one center | `layout-twopi.md` |
| Recursive cluster or array packing | `layout-osage.md` |
| Hierarchical area or part-to-whole view | `layout-patchwork.md` |
| Meaningful boundaries and cross-cluster relationships | `clusters.md` |
| Peer alignment or stable layered order | `ranks.md` |
| Field-level ports, record labels, or rich table labels | `ports-and-labels.md` |
| Familiar shapes as supplementary semantics | `semantic-shapes.md` |
| Edge labels, constraints, route ambiguity, or reciprocal edges | `edge-routing.md` |
| Links, images, tooltips, or other active content | `interactive-content.md` |
| Deterministic or nondeterministic finite automaton | `automata.md` |
| Labeled transition system | `transition-systems.md` |
| Petri net | `petri-nets.md` |
| Decision tree | `decision-trees.md` |
| Fault tree | `fault-trees.md` |
