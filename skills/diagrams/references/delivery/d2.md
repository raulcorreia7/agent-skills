# D2 Readiness And Rendering

Prefer an approved package manager or pinned official release. The upstream
install script does not itself verify release signatures; inspect it with
`--dry-run` before use. Use Homebrew on macOS, the official MSI on Windows, or
a reviewed pinned archive or source build on WSL/Linux.

```text
d2 --version
d2 layout
d2 validate diagram.d2
d2 fmt --check diagram.d2
d2 --theme 0 --layout elk diagram.d2 diagram.png
```

Pin the D2 version, layout, fonts, assets, and PNG backend. D2 0.7.1 expected
its matching Playwright/Chromium driver; another Playwright installation did
not satisfy that evaluated runtime. Trust render exit status, not file
existence, because failed D2 output can be partial. Do not substitute formats or
download an unpinned browser without notice. Validate one selected layout, not
a Dagre-by-ELK matrix.

D2 can export multi-board layers, scenarios, or steps as GIF. Use it only when
short staged change is the question. Keep all meaning in a static PNG too and
respect reduced motion. `style.animated` does not make a single board a GIF.

Sources: [D2 installation](https://d2lang.com/tour/install/),
[CLI](https://d2lang.com/tour/man/), and [exports](https://d2lang.com/tour/exports/).
