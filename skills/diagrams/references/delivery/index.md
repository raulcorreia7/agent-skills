# Delivery Router

Load only the file matching the delivery decision or renderer in use.

| Trigger | File |
|---|---|
| Choose native source, project rendering, or a static image | `rendering.md` |
| Check whether authors, CI, and readers can use the toolchain | `readiness.md` |
| Render unreviewed source, configuration, fonts, icons, images, imports, or includes | `security.md` |
| Use the bundled `scripts/render.py` helper | `render-helper.md` |
| Use Mermaid CLI or a native Mermaid renderer | `mermaid.md` |
| Use Graphviz CLI, engines, plugins, or fonts | `graphviz.md` |
| Install, validate, render, or export D2 | `d2.md` |
| Determine a destination's native capability | `platforms.md` |
