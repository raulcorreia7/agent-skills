# General Recommendations

Issue 9 identifies these as recommendations, not STE rules. Report them as
advisory unless another rule or publication directive makes them mandatory.

| ID | Operational check |
|---|---|
| GR-1 | Use `that` after a verb that introduces a subordinate clause when it makes the clause boundary clearer. |
| GR-2 | Use `with` only for association, help or sharing, or an instrument. Put a condition first. Use the primary action as the sentence's verb. |
| GR-3 | Use the exact noun instead of an ambiguous pronoun. Do not use `he` or `she`. |
| GR-4 | Use bare `this` only with one unmistakable referent. Otherwise, name the condition, cause, or item. |
| GR-5 | Make sure that false friends and familiar cognates have the intended English meaning. |
| GR-6 | Do not use `e.g.`, `i.e.`, or `etc.`. Use an English alternative or omit it. |
| GR-7 | Use inclusive, gender-neutral, nondiscriminatory language. Use `man` or `woman` only when the context requires the distinction. |
| GR-8 | GR-8 permits possessive apostrophe-s when it is grammatically correct. Use a style guide if uncertain. |

Source: GR-1 is on official PDF page 123. GR-2 is on page 124. GR-3 and GR-4
are on page 125. GR-5 and GR-6 are on page 126. GR-7 and GR-8 are on pages
126–127.

## Automation Boundary

Software can find Latin abbreviations, gendered pronouns, bare `this`, and
some uses of `with`. These matches remain advisory `Review` items. False
friends, clear referents, clause boundaries, inclusion, and grammatical
possession require human judgment.
