# Live Resources And Sensitive Data

- Confirm scope and data classification before broad queries. Start with
  inventory and aggregates, then narrow.
- Exclude secrets, customer payloads, personal data, tokens, connection strings,
  and unnecessary identifiers. Redact evidence.
- Treat missing permissions, dimensions, retention, sampling, or aggregation as
  limits, not absence of a problem.
- Never change capacity, scale, SKU, placement, quota, retention, reservations,
  routing, or monitoring merely to measure without approval.
