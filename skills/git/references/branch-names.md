# Branch Names

Fallback shape when the repository has no convention:

```text
type/short-subject
type/scope-short-subject
type/scope-short-subject-1234
```

- Use lowercase words separated by `-`.
- Keep one issue or work-item suffix when it helps traceability.
- Leave out URLs, random abbreviations, and temporary notes.
- A branch name can be less formal than a PR title, but it should make sense
  without the linked issue.
