# Branch Names

Follow local conventions first. Otherwise use a readable branch shape:

```text
type/short-subject
type/scope-short-subject
type/scope-short-subject-1234
```

- Use lowercase words separated by `-`.
- Keep one issue or work-item suffix when it improves traceability.
- Avoid URLs, random abbreviations, and temporary notes.
- Keep branch names less formal than PR titles but understandable without the
  linked issue.

Suggest a better name when useful. Do not rename a branch without explicit
approval.
